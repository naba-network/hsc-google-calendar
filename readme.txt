Shows free ice time slots from Google Calendar and makes them bookable on the club website.

== Description ==

Teams and ice times are maintained in Google Calendar. Free slots become bookable via the website.
The plugin updates itself from GitHub releases.

== Installation ==

1. Download `hsc-google-calendar.zip` from the latest GitHub release.
2. Upload it under Plugins > Add New > Upload Plugin and activate it.
3. Later versions appear as regular updates in the WordPress admin.
